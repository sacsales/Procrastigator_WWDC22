# Procrastigator_WWDC22
My second winning WWDC Swift Student Challenge project, Procrastigator!

Similar to Note Values, I made this pretty early on in my coding journey (I was 13 here) so it's definitely not the cleanest or most efficient. Regardless, this was one of my favorite projects - with all original art by me! 

Built using SpriteKit and SwiftUI. 


https://github.com/user-attachments/assets/054552a7-ab8a-439b-b781-5dd7fe601759



## Usage:
- Download the .zip, and open in either Swift Playgrounds/XCode.
- Please run full screen or on an iPad simulator in landscape mode for best experience!
